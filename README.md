# Digital-Lock-System-Using-Arduino-Uno
**Digital Lock System Using Arduino Uno**  This project is developed using Arduino Uno, a 4×4 keypad, and a 16×2 LCD display. The user enters a password using the keypad. If the password is correct, the LCD displays “Access Granted”; otherwise, it displays “Access Denied”. The project is simulated using Wokwi and programmed in Embedded C/C++.
